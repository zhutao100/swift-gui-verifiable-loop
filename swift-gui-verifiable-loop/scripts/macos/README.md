# macOS helper scripts

- `tcc_attribution_tail.sh`: captures a short TCC `AttributionChain` log slice while reproducing a privacy prompt.
- `collect_tcc_identities.sh`: prints bundle identifiers and designated code requirements for PPPC profile authoring.

These scripts do not grant permissions. They collect the evidence needed for a human or MDM administrator to grant the right executable/bundle rather than guessing.
